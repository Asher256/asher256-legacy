# FM-Song (version 1.3.2)

Auteur: Asher256

## Introduction

FM-Song est un tracker convivial et intuitif qui permet de créer des
musiques. Il peut être tout autant utilisé par des utilisateurs novices ou
expérimentés. Avec FM-Song, la création de musique est facile et accessible,
même pour ceux qui n'ont jamais créé de musique sur un ordinateur auparavant.

Le tracker FM-Song et la librairie FmLib fonctionnent sous DOS et la carte son
compatible avec SoundBlaster. FM-Song peut être émulé dans les ordinateurs
récents le logiciel Dosbox.

Si vous souhaitez tester les musiques crées avec FM-Song et FmLib, vous pouvez
essayer le jeu vidéo MisterKid (du même auteur), qui vous permettra d'écouter la
qualité des musiques et l'efficacité de FM-Song dans la création de musique pour
les jeux vidéo.

FM-Song est peut jouer jusqu'à huit instruments de musique simultanément et
offre plus de 70 instruments différents à votre disposition (Piano, flûte...).
pour enrichir votre composition.

### Utiliser vos compositions dans un programme Quick Basic

FM-Song vous offre la possibilité d'utiliser vos musiques dans vos programmes
QBasic grâce à la bibliothèque logicielle FmLib (incluse avec FM-Song). Vous
pouvez utiliser FM-Song pour ajouter une bande son personnalisée à vos jeux
vidéo ou pour créer des morceaux de musique originaux pour vos projets créatifs.

Avec FmLib, vous avez la possibilité de charger vos musiques *.fms dans votre
programme QBasic. La librairie FmLib joue la musique en arrière-plan et ne
ralentit pas votre programme QBasic.

## Foire aux Questions

### Raccourcis clavier
- **Alt-f** : Ouvrir le menu fichier.
- **Ctrl+L** : Sélectionner toutes les notes du channel actuel.
- **Ctrl+D** : Effacer toutes les notes du channel actuel.
- **Shift \+ haut ou bas** : Sélectionner Des note pour Copier ou Coller.
- **Ctrl+C** : Copier
- **Ctrl+V** : Coller
- **\- et +** : Changer l'octave.
- **L et M** : Changer de track.
- **Espace** : Une note vide.
- **e chap** : Stopper la musique : "Stop"
- **P** : Aller a la dernière note : "FF"
- **O** : Revenir a la première note : "Rew"
- **Entr ee** : Jouer la musique : "Play"
- **F1 a F8** : éteint ou allume un channel dans le track actuel.
- **azerty** : Ajouter une note DO-RE-MI-FA... (A pour DO, Z pour RE...)
- **Ctrl-azerty** : Le même chose mais avec une dièse.
- **Shift-Suppr** : Insérer une note dans tout les channels.
- **Shift-Ins** : Effacer une note dans tout les channels
- **Suppr** : Effacer une note dans le channel actuel.
- **Ins** : Insérer une note dans le channel actuel.
- **Ctrl-N** : Nouveau
- **Ctrl-O** : Ouvrir
- **Ctrl-E** : Enregistrer
- **Ctrl-Q** : Quitter le programme.

### Changer la langue

Pour que FM-Song soit en français modifiez 'FMSONG.INI':
```
langage = "french"
```

### Comment créer une musique
- Appuyez sur **Fichier \-- > Nouveau ** (Alt-f, puis Enter) pour créer un nouveau projet.
- Choisissez 40 notes
- Ouvrez le menu **Édition-->Instruments** et choisissez dans le menu déroulant: **PIANO**. Cela changera l'instrument du 'channel 1'.
- Enfin, créez votre musique dans le premier canal (Appuyez sur A pour DO, Z pour RÉ, E pour MI...)
